# Vibe Coding in VS Code（中文）

> 使用 DGX Spark（或任意可运行 Ollama 的机器）作为 **Vibe Coding** 助手，通过 Continue 插件把 Ollama 模型接入 VS Code。

![示意图](attachments/overview.svg)

## 你将获得什么

- VS Code 内的对话/编辑/补全能力（由 Continue 提供 UI）
- 后端模型由 Ollama 提供（例如 `gpt-oss:120b` 或更小的模型）
- 可选：把 Ollama 暴露到局域网，让工作站连接远端 DGX Spark

## 前置条件

- 已安装 VS Code
- 已安装 Continue（VS Code 插件）
- 能联网下载模型（首次拉取会比较慢）
